# HotThemeRotator 使用说明书

> 面向单人使用。配套：启动看 `README.md` runbook，规则看 `docs/02_GOVERNANCE.md`，状态看 `PROJECT_STATUS.md`。

## 快速上手手册（2026-07-04 现行版 — 覆盖 P21 计划板 / P22 纪律板 / 远程访问）

### 0. 三条铁律(每天默念)
1. 系统**永远不下单**。所有买卖你自己在券商 App 里做,做完回来记账。
2. 屏幕上的分数**不是胜率**。它只决定候选排第几,不代表会涨。
3. 红章黄章是**你自己定的规矩**在提醒你,听不听是你的决定——但不许装没看见。

### 1. 打开面板
- **电脑**:浏览器开 `http://127.0.0.1:8000/`。打不开=服务没跑,在项目目录执行:
  `python -m uvicorn api.main:app --host 127.0.0.1 --port 8000`
- **手机**:装 Tailscale(和电脑同一账号)→ 开 `http://100.118.51.81:8000/login?token=<你的token>` 登一次,之后直接访问。token 遗失/失效=让 Claude 重启远程服务发新 token。

### 2. 每天早上 3 分钟(按这个顺序看)
1. **顶栏**:有黄色"示例数据"条=数据有问题,先别信当天面板。
2. **市场温度条**:全红过热=容易追高的日子,管住手。
3. **持仓纪律板**:你手里的票有没有章?
   | 章 | 意思 | 你该做什么 |
   |---|---|---|
   | 计划内持有 | 在你的止损和止盈之间 | 不动 |
   | 已越首止盈参考 | 浮盈超过 +2% 了 | 想一想:落袋一部分? |
   | **止损参考已破**(红) | 浮亏超过 −4% 了 | **必须做一个决定**:止损,或明确说"我改规矩继续拿" |
4. **交易计划板**:今天值得看的候选(想买东西才看,不想买跳过)。

### 3. 想买一只股票:五步
1. 在**交易计划板**找到它(不在里面就用顶栏搜索框输代码,如 `7203`)。
2. 看**状态章**:
   | 章 | 意思 |
   |---|---|
   | 结构就绪 | 数据齐、不追高、买得起,可以细看 |
   | 仅观察·不追 | 涨太多了/龙头过热,系统按你的反追高规矩劝退 |
   | 仅 S株 可行 | 一手(100株)超出你账户承受,只能碎股买 |
   | 超出账户承受 | 现金不够,别看了 |
   | 数据不足 | 数据缺,不给参考 |
3. 看**价位**:`建议价位·均衡`=挂单参考价;`止损参考`=买之前先记住退路在哪;`目标参考`三档=止盈档(+2/+3/+5% 一带)。
4. 看**仓位**:"整手 N株 / S株 N株"=按 1% 资产风险算出来的数量上限,别超。
5. 看**条件**:4 个勾叉(开盘中?/不追高?/有公司级新闻?/龙头没过热?)。勾越多越顺;想知道这只票**贵不贵**(价值分位),问 Claude:"查 XXXX.T 的价值分位"。

### 4. 买/卖完之后:必须记账(不记,纪律板和胜率统计全失灵)
右栏持仓卡 → `+ 成交` → 填方向/数量/价格 → **预览**(核对 NAV 变化)→ **确认**。入金出金点 `现金`。

### 5. 收盘后:什么都不用做
16:00 自动采集(电脑开着就行)。漏了就手动跑:`python tools\daily_routine.py --mode afterclose`。

### 6. 每周看一次
- **历史候选复盘卡**:系统选的票整批 vs 大盘,涨没涨过指数,一目了然。
- 让 Claude 算**你的胜率**:每笔平仓自动入账,样本越多越准。

### 7. 出问题找 Claude 的暗号
"面板打不开" / "数据是旧的" / "查 XX 的价值分位" / "算我的胜率" / "今天 XX 板块暴跌怎么分析" / "改我的止损参数"。数据每天有备份,坏不了。

## 0. 一句话定位 + 最重要的心态

HTR 是一个**只读的研究驾驶舱**：把日股的市场温度、热点主题、龙头候选、价格阶梯、持仓、新闻、反思汇到一屏，帮你**看清、想清**，然后**你自己在券商手动下单**。

**记住三条（贯穿每张卡）：**
1. **分数是"研究排序信号",不是胜率/概率。** 经 P12 leak-resistant 验证，系统目前**没有被证明的 edge**（模型连基线都打不过、有效样本仅 ~11 个日期簇）。所有分数标着"未校准"，别拿它当赢面下注。
2. **永远不下单。** HTR 不连券商、不发订单（Rule 3）。所有"价位/止盈/止损"都是**参考数字**，由你手动执行。
3. **静态价格 = 收盘价。** 顶栏标"休市"时，价格是上一交易日收盘价，不跳动、不模拟实时（Rule 11.9）。

## 1. 每天怎么操作（周一起的节奏，Rule 15.5）

**关键：每日自动任务只做"采集 + 自检",不自动开网页。看盘面要你自己启动。**

1. **启动看板**（想看时手动跑一次）：
   ```powershell
   cd E:\AIagent_project_260213\worker-quant\quant_trading\HotThemeRotator
   python -m uvicorn api.main:app --host 127.0.0.1 --port 8000
   ```
   浏览器开 `http://127.0.0.1:8000/`。
2. **盘前**：看顶栏新鲜度标（应是"休市"或"开盘"），看有没有黄色"示例数据"横幅（正常应没有）。`HTR_Daily_Preopen` 08:30 已自动跑过 smoke 自检。
3. **盘中**：当只读研究用——浏览候选、读龙头/策略/因子、看 K 线。**别把分数当赢面。** 真要交易，自己判断、去券商手动操作。
4. **成交后**：右栏持仓卡点 **`+ 成交`** → 填已成交的方向/数量/价格 → **预览**（看 NAV 变化）→ **确认提交**（写入账本）。入金/出金/分红点 **`现金`**。
5. **收盘后**：`HTR_Daily_AfterClose` 16:00 自动刷候选→emit→sweep 采 forward 样本（机子要开着；漏了就手动 `python tools\daily_routine.py --mode afterclose --asof <日期>`）。
6. **收盘记**：有异常（数据错、标签矛盾）写一行进 `PROJECT_STATUS.md`。

## 3. 顶栏 + 5 个功能 chip

| 元素 | 显示什么 | 怎么用 / 怎么理解 |
|---|---|---|
| **asof 时间** | 数据截止时刻（JST） | 数据有多新的真相 |
| **休市 / 开盘 标** | `休市 · 数据为 {日期} 收盘` 或开盘绿点 | 休市时价格是收盘价、不跳动；从 asof vs tradeDate 真实算出 |
| **未校准 · 研究分 n=X** | 校准样本量 | 永远提醒：分数没校准，n 是配对样本数 |
| 🔎 **搜索框** | 输 4 位代码（如 `7203` 或 `7203.T`） | 池内票直接切；池外票走真实 `/profile` 校验，标"非今日热点候选"`in_screener=False`，分数仍未校准 |
| ★ **关注** | 你的关注列表（localStorage） | 加/移关注、点"查看"切到该票。**仅存本地浏览器**，不影响持仓/校准（服务端 watchlist 暂未接，等开推送再接） |
| 🧠 **提案** | 反思系统的改进提案（真实 `/api/proposals`） | 大白话摘要 + 证据强度(弱/中/强) + 折叠技术细节；可接受/拒绝(真写库)。**现在样本不足→多半空态"暂无待批提案"** |
| 📐 **校准** | K-fold 验证判定（真实 `/api/calibration/reliability`） | 现状=**降级 downgrade**：OOS Brier 0.2823 ≥ 随机 0.25 → 判定"无效信息" → 强制未校准。这是诚实状态 |
| 📢 **推送** | 桌面/邮件/Telegram 通知开关 | **默认全关**。开启需输确认句双重确认（真写审计日志，后端 stage-2 未满足会拒绝）；有 dry-run 演练。Local Beta 阶段建议保持全关 |

## 4. 逐卡说明（每张卡：显示什么 · 怎么读 · 功能）

### 市场温度计（顶部横条）
- **显示**：6 个市场方块。每块=名称、`OPEN/CLOSED` 角标、**温度 0–100°**、现价、涨跌%、迷你走势线。
- **读法**：温度=多因子合成（动量·量能·板块共振·隐含波动）。图例 **≥70 过热 / 50–69 升温 / 30–49 平温 / <30 冷**。过热≠该买，是"情绪高、易追高、风险大"。
- **功能**：纯展示。日股是主场，A股/美股/USDJPY 是**外部温度**（只影响许可与权重，不单独触发买入）。

### 左栏 · 候选清单
- **显示**：screener_v2 按研究分排序的票：`#排名 · 代码 · 涨跌% · 中文名/主题 · 分数 + 热度条`。
- **读法**：分数是**未校准排序信号**（0–100 视觉热度），高≠高赢面。
- **功能**：**点任意一行 → 中栏整列切到该票**（龙头卡/K线/策略/因子/命中/AI 全跟着变）。这是主导航。

### 左栏 · 主题热力
- **显示**：六板块热度方块（热度°+ 动量箭头 + 该板块 2 个龙头）+ 下方主题排序条。
- **读法**：哪个板块在升温、谁领涨。热度由价格/新闻派生。
- **功能**：纯展示（不可点切，用候选清单切票）。

### 左栏 · 宏观新闻热度（P10-26）
- **显示**：HTR 自采的宏观/政策/汇率/跨市场新闻，按 货币/财政/汇率/贸易/海外 分类，每类条数 + 最近标题（可点开原文）。
- **读法**：补上"per-ticker 新闻看不到的上游催化"。透明关键词分类（无 LLM，可审计）。
- **功能**：单击"⋯ 展开"看更多（卡内滚动）。**无宏观新闻时整卡不显示**。

### 中栏 · 候选 LEADER 卡（当前选中票）
- **显示**：代码 + 中/日文名 + 现价 + 涨跌%；一句话定性 `one_liner`；4 个 MiniStat（**研究分(未校准)** / 买入·均衡 / 首止盈 / 止损参考）；右侧**七档阶梯迷你图**（含"现价"横线）。
- **读法**：MiniStat 的价位都是**参考**。若标"ⓘ K-fold 降级"，鼠标悬停看降级原因。
- **功能**：右上 **☆加关注 / ★已关注** 切换（localStorage）；主题/优先级 chip。

### 中栏 · 价格走势 K 线
- **显示**：蜡烛图 + **MA20/MA60** + 52 周高低线 + 下方量能 + **七档阶梯叠加线**。标题 chip 显示根数（如 `120D`）。
- **读法**：**鼠标悬停十字线** → 看那根的 OHLCV、相对前收涨跌%、均线值（都是历史事实，非预测）。价格是拆股复权后的连续序列（Rule 11.9.6）。
- **功能**：点标题栏 ▾/▸ 折叠；可滚轮缩放、拖动平移（只重窗已有bar，不造数据）。

### 中栏 · 策略卡片（Rule 11.6 强约束）
- **显示**：**置顶不可折叠的 advice-only 横幅 + "Rule 3 手动执行"声明**（始终在）；**风险标记**（Rule 12：追涨/冷静期/集中度/数据陈旧，带 BLOCK/WARN/INFO 等级 + 规则号；无风险也明写"当前无活跃风险标记"）；**七档价格阶梯表**（标签/价位/相对参考%）；催化日历 + "非建议持有至该日"声明；底部 `score_status`。
- **读法**：价位是"建议价位/目标参考/止损参考"——**名词，不是"买入"指令**。风险标记是给你泼冷水的，认真看。
- **功能**：点标题折叠正文（横幅+声明不折叠）。

### 中栏 · 详情 tabs
四个标签页（点切换，展开内容向下推不遮挡）：
- **因子构成**：`screener_score / mom_20 / mom_60 / sharpe_20 / sortino_60 / vol_z / adv / in_screener`。**分数构成=排序信号非概率**。注：`sortino_60 / vol_z` 后端暂无 → 显"—"（不是 0，是没数据）。
- **历史命中**：总数/已结算/命中/**原始频率%**（带 `uncalibrated_evidence` 标，**非胜率**）+ 逐条 `trade_date · raw_score · 命中/未命中/待结算 · 来源(bootstrap/live)`。**注意：bootstrap 来源的样本已按 P12-01 被隔离，不计入校准**。
- **AI 综合**：本地 LLM（gemma）的中文研究综述——**只叙事、无任何概率/胜率数字**（正则强制拦截）。Ollama 没起时可能先显占位，起了再覆盖。
- **Bull / Bear / Judge**：多空+裁判三段辩论简报（每段独立过无概率正则）。

### 右栏 · 持仓 Portfolio
- **显示**：**NAV 总资产** + **浮动盈亏(¥ + %)** + NAV 走势线（`navHistory` 后端暂无时不显）+ 持仓/现金占比条 + 逐持仓（代码、`股数@均价`、市值、浮盈¥+%、双向盈亏条）。
- **读法**：这是你的真实账本（ADR-0008 后 HTR journal 是唯一真相源）。当前 1306.T 500 股 / NAV ≈¥40 万。
- **功能**：右上 **`+ 成交`** 录已成交交易（**预览 commit:false 看 NAV 变化 → 确认提交 commit:true 写账本 → 刷新看持仓**）；**`现金`** 录入金/出金/分红。**这是不下单、只记账**（Rule 3 carve-out）。

### 右栏 · 新闻催化
- **显示**：近 6h per-ticker 新闻时间线（最多 7 条）。
- **读法**：催化事件速览。（"2 high"标签当前为占位，按 backlog 待按真实权重计数。）
- **功能**：卡内滚动看更多。

### 右栏 · Daily Cockpit
- **显示**：激活阶段（`Stage 0 pull-only`）+ watch/quotes/silent 三指标 + 关注票的报价状态 + TDnet 披露条数；右上 `pull-only`（绿）/`blocked`（红）标。
- **读法**：Stage 0 = 只在你打开时拉取、**不推送**。silent=静默队列（攒着不打扰）。
- **功能**：纯展示。

### 右栏 · 决策日志 §8.6
- **显示**：当日决策记录（预测/候选行，含 model_version、输入快照、理由、数据缺口）。
- **读法**：空时显式空态——空≠坏，是"还没攒到记录"。
- **功能**：卡内滚动。

## 5. 颜色 / 术语速查

- **红 = 看跌/止损/过热/BLOCK**；**绿 = 看涨/盈利**；**黄 = 警告/升温/休市**；**灰 = 中性/无数据(—)**。
- **未校准研究分 (uncalibrated_research_score)**：排序信号，非概率。**贯穿全系统的红线。**
- **七档阶梯**：激进/均衡/保守 买入 + 止损 + 首/次/冲 止盈——全是**参考价位**。
- **K-fold 降级 (downgrade)**：模型 OOS 表现没打过基线 → 强制不显胜率。
- **bootstrap vs live**：bootstrap=历史回填证据（已隔离）；live=真实 forward 样本（在攒）。

## 6. 系统永远不会做的事（红线）

- 不连券商、不下单、不模拟下单（Rule 3 + §10 gate 8）。
- 不把任何数字标成"胜率/概率"——除非真过了 leak-resistant 校准（目前没有）。
- 不模拟价格跳动、不伪造新鲜度（Rule 11.9）。
- 不自动推送——除非你手动开（双重确认 + 审计日志）。

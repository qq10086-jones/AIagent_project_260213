## 一、P0 修复：Sprint 信号管线断裂

### 发现经过

用户反馈"市场明明要涨，为什么系统建议清仓？"。经过逐层排查：

1. `action_plan` 显示 `SELL: 4005.T | Regime: on` — regime 正确识别看多，但仍推荐卖出
2. `target_weights_meta` 显示 `selected_count: 0, export_row_sum: 0.0` — Sprint 信号无法选出任何股票
3. `factor_family_summary` 显示 `active_factor_count: 0` — 所有因子族为空
4. **根本原因**：`feature_daily` 表只包含基本面特征（dividend_yield, roa_op 等 7 个），**从未包含过价格技术特征**（mom_consist, high52w, vol_z, sharpe_60 等 20 个）

### 影响范围

- Sprint 信号自上线以来**从未正确产生过 target_weights**
- 过去的交易决策完全基于 screener 排名或手动判断，而非信号驱动
- `signal_mode_compare_report` 中 sprint_momentum 的 return、Sharpe 全为 0.0

### 修复

| 文件 | 变更 |
|------|------|
| `compute_price_features.py` (新增) | 从 `daily_prices` 计算 20 个技术特征并写入 `feature_daily` |
| `daily_run.py` step 1.3 | 在 screener 之前调用 compute_price_features |
| `daily_run.py` step 1.4 | 健康检查：验证 6 个 sprint 必需特征存在 |
| `tests/test_sprint_integration.py` (新增) | 9 个集成测试覆盖 feature → signal → target_weights 全链路 |

## 二、P1 修复：Entry/Exit 逻辑解耦

### 问题

Sprint 信号的 `sprint_entry_check`（进仓条件）被用于所有股票，包括已持有的仓位。当市场中没有新候选通过 entry_check 时，系统将已持仓位也排除，生成 target_weights=0，导致 make_decision 产生机械性 SELL。

这在实盘中表现为：持有的 4005.T 含盈利 +5.1%，止损未触发，regime=on，但系统仍推荐卖出。

### 修复

**`sprint_signal.py` `generate_sprint_artifacts()`**：
- 加载当前持仓（positions 表）
- 新进仓候选：使用 `sprint_entry_check`（严格条件）
- 已持仓位：使用 `sprint_exit_check`（止损/持有期/regime=off）
- 组合逻辑：已持仓优先占位，剩余槽位才考虑新进仓

**`make_decision.py`**：
- 增加 `entry_filter_hold` 安全网：当 target_weights 为空且 benchmark != off 时，保留现有持仓
- 取消 DB 中的旧 SELL 订单

修复后结果：`Action plan: No trades required | HOLD: 4005.T | Regime: on`

## 四、Cross-Asset 权重优化

### 方法

- 数据：2024-04-10 ~ 2026-04-08（519 obs）
- 信号：US 指标（SP500/VIX/SOX/NKD/原油/金/铜）lag 1 day，USDJPY 无 lag
- 目标：next-day 1321.T return
- 验证：walk-forward（train=346d, test=173d）

### 结果

| 指标 | 旧权重 | 新权重 | 说明 |
|------|--------|--------|------|
| sp500 | 0.20 | 0.08 | 对日经预测力弱（IC≈0） |
| usdjpy | 0.15 | 0.08 | 24h 交易，lagged IC 低 |
| vix | 0.10 | 0.10 | 风险情绪指标，保留 |
| nk_futures | 0.15 | 0.12 | 直接预测力，略降 |
| crude_oil | 0.15 | 0.12 | 显著 IC (p<0.05) |
| gold | 0.05 | 0.12 | 避险信号，walk-forward 支持上调 |
| copper | 0.05 | 0.20 | 最强预测力 (IC=0.12, p<0.01)，铜=全球制造业景气 |
| sox | 0.10 | 0.18 | 半导体映射 (IC=0.14, p<0.01) |

**Walk-forward test IC: 0.259**（vs 旧权重 0.231，改善 +0.028）

初始全样本优化给出铜=0.35，但 walk-forward 验证支持约 0.16，因此保守设定为 0.20。


# Design Patch
## MetaGPT-Inspired Agent Contract System
Version: vNext-patch-001

This patch introduces a MetaGPT-inspired agent contract layer into OpenClaw Nexus.

Instead of embedding the MetaGPT runtime, we adopt its design principles:
- role-based agents
- SOP-driven prompts
- structured outputs

Subsystem introduced:

Prompt Script Registry

Purpose:
Ensure deterministic behavior of agents and enforce schema-based outputs.
